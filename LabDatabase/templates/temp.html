// 1. 初始化ECharts实例 const chart = echarts.init(document.getElementById('treeChart')); // 2. 设置图表配置项 const option = { series: [{ type: 'tree', data: [treeData], // ... 其他配置 }] }; // 3. 为图表设置点击事件监听 chart.on('click', function (params) { // params 包含点击的节点信息 if (params.componentType === 'series' && params.seriesType === 'tree') { const nodeData = params.data; console.log('点击的节点:', nodeData.name); // 执行自定义操作 } }); // 4. 渲染图表 chart.setOption(option);

🎯 基本点击事件

通过 chart.on('click', callback) 监听节点点击事件，获取节点信息并在控制台输出。

🔍 节点信息获取

事件参数 params 包含完整的节点信息：名称、值、深度、子节点列表等。

🎨 视觉反馈

点击节点后可以动态修改节点样式，如改变颜色、添加动画、显示高亮效果等。

🔄 动态操作

基于点击事件可以实现添加节点、删除节点、展开/折叠、高亮路径等动态操作。
